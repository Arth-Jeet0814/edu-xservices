# Global Edge

Create a modern, attractive, responsive overseas education consultancy website that helps students explore study destinations, search universities and courses, and submit enquiries.

The website should feel professional, trustworthy, premium and student-friendly. Use a clean international education theme with strong visual hierarchy, generous spacing, subtle animations, modern cards and clear call-to-action buttons.

Design Style

Use:

Clean white background

Deep blue as the primary brand colour

Light blue gradients for banners and highlights

Warm accent colour such as orange or gold for call-to-action buttons

Rounded cards and buttons

Soft shadows

Modern sans-serif typography

High-quality images of international students, universities and global destinations

Smooth scrolling and subtle hover animations

Fully responsive design for mobile, tablet and desktop

Avoid an overly crowded design, excessive animation or too many colours.
